## Decisions before an external return

The following are proposed numerical comparison tolerances chosen for this benchmark; no external party has agreed to them. A new frozen version is needed if changed. Both cases must be input-matched and independently solved and reported. Require a baseline strike within 5 mm Euclidean distance of the reference, |B·n| within max(0.02 T, 10% of the local value), and agreement on the baseline side. Ask for a displacement uncertainty in strike position for each mesh pair, supported by an equilibrium-refinement comparison plus tracer convergence. Apply a minimum 2 mm corner guard. An endpoint is resolved only if its distance to the corner exceeds max(2 mm, reported strike uncertainty); check both solvers. Do not substitute tracer precision for grid uncertainty. PASS for the crossing requires resolved negative baseline and positive displaced for both. FAIL for the crossing if baselines agree and the external displaced solution remains resolved on the original face while the local displacement is resolved on the adjacent face. Missing uncertainty, baseline disagreement, a third-face hit, absent independent results or inconclusive refinement gives UNRESOLVED. Report displaced coordinate/normal-field agreement at the same tolerances as a separate quantitative result. Apply the identical representative heat map only after magnetic agreement; report ratio, separately from the face verdict.
